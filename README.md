# Fundamentos Python e Lógica de Programação

Repositório criado para registrar meus estudos, exercícios e práticas de lógica de programação utilizando Python.

## Objetivo

Desenvolver raciocínio lógico, praticar fundamentos da linguagem Python e organizar minha evolução através de exercícios separados por tema.

## Conteúdos estudados

- Variáveis
- Operadores aritméticos
- Operadores de comparação
- Operadores lógicos
- Condicionais
- Laços de repetição com `for`
- Laços de repetição com `while`
- Funções
- Listas, conjuntos, tuplas e dicionários
- Tratamento de erros
- Noções de Programação Orientada a Objetos
